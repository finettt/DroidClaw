# Обновления

DroidClaw проверяет GitHub на наличие новых релизов и сообщает, когда появляется
новый. Если доступна более новая стабильная версия, приложение показывает
диалог с примечаниями к релизу и ссылкой на его страницу, где можно скачать
APK. Приложение никогда не скачивает и не устанавливает ничего самостоятельно.

## Что делает

- Запуске приложение читает `https://api.github.com/repos/finettt/DroidClaw/releases/latest`.
- Если последний стабильный тег новее той версии, которая у вас установлена,
  появляется диалог с названием релиза, примечаниями (обрезаны до ~1500
  символов) и двумя кнопками:
  - **Открыть релиз** — открывает страницу релиза в браузере, где можно скачать
    APK.
  - **Позже** — закрывает диалог.
- На экране «О приложении» (выдвижное меню → «О приложении») баннер отображается,
  если известно о более новом релизе, но диалог запуска не был показан, а кнопка
  **Проверить обновления** запускает ручную проверку.

## Как часто проверяется

- Проверка при запуске выполняется не чаще одного раза в 24 часа; интервал
  запоминается в локальном параметре (`last_update_check_at`).
- Кнопка **Проверить обновления** на экране «О приложении» выполняется всегда,
  независимо от 24-часового интервала.
- Если GitHub ограничивает запрос (HTTP 403/429), приложение показывает
  «Не удалось проверить обновления»; можно попробовать снова. Если в репозитории
  ещё нет полных релизов, это считается «Актуальной версии».

## Отключение

Проверка включена по умолчанию. Чтобы остановить автоматическую проверку при
запуске, отключите **Автоматически проверять обновления** на экране «О приложении».
Когда функция отключена, путь запуска не выполняет сетевых запросов. Ручная кнопка
**Проверить обновления** продолжает работать.

## Локальные сборки

В локальных/отладочных сборках версия приложения — это git-хеш или `dev`, а не
тег CalVer, поэтому проверка при запуске полностью пропускается: приложение
никогда не связывается с сетью из локальной сборки. Ручная кнопка
**Проверить обновления** по-прежнему показывает последний релиз.

## Конфиденциальность

Приложение обращается только к `https://api.github.com/repos/finettt/DroidClaw/releases/latest`,
чтобы сравнить последний релиз с вашей версией. Ничто не отправляется обратно в
DroidClaw.

## Версии

DroidClaw помечает релизы формату CalVer (`YYYY.MM.DD`, с суфиксом `.N` для
повторных релизов в тот же день). Приложение сравнивает теги релизов по
разрядам по номерам, поэтому `2026.10.10.1` новее, чем `2026.10.10`.
