# Установка окружения Linux

DroidClaw может установить закреплённый базовый образ Ubuntu 24.04.5 через **Настройки агента → Окружение Linux**. Образ выбирается по ABI устройства: для `arm64-v8a` используется Ubuntu `arm64`, для `x86_64` — `amd64`.

## Установка

Нажмите **Установить Ubuntu**. DroidClaw загрузит закреплённый архив Ubuntu, проверит SHA-256, распакует его, запишет настройки DNS и источников APT и отметит образ как готовый. На экране отображаются текущее состояние и прогресс загрузки.

Образ и загруженный архив хранятся в приватном каталоге приложения `files/distro/`. Они исключены из резервного копирования Android. Кнопка **Удалить образ** удаляет оба объекта.

Эта функция только устанавливает образ. Она не меняет backend оболочки и не направляет `execute_shell` через PRoot.

## Лимит диска

Параметр **Лимит диска (МБ)** по умолчанию равен 2048 МБ. Перед установкой DroidClaw проверяет, что на разделе данных приложения достаточно места для этого лимита, архива и запаса. Тот же лимит на стороне Android доступен для последующей интеграции команд distro.

Это рекомендуемый предел, а не квота файловой системы. PRoot не может запретить процессу внутри Ubuntu занять больше места. DroidClaw измеряет образ со стороны Android и может отклонять последующие операции distro при превышении лимита, но не обеспечивает жёсткую квоту.
