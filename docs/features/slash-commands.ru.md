# Слэш-команды

Введите `/` в поле ввода чата, чтобы выполнить команду локально, а не отправлять
сообщение агенту. Пока вы вводите префикс `/`, выше поля ввода появляются строки
подсказок с подходящими командами; нажмите на нужную, чтобы подставить её в поле.

Команды обрабатывает само приложение: они не доходят до LLM, а их вывод
показывается временным сообщением, которое не сохраняется в истории сессии.
Любой текст, начинающийся с `/`, но не являющийся известной командой,
отправляется агенту как обычное сообщение.

## Доступные команды

| Команда | Описание |
|---------|----------|
| `/effort [level]` | Показать или установить уровень усилий (reasoning effort). Уровни: `low`, `med`, `high`, `xhigh`, `max`. Уровень задаёт и параметр reasoning, отправляемый в API (для моделей с поддержкой рассуждений), и бюджет итераций агента для последующих запусков. |

Примеры:

```
/effort          →  Effort: med (turn budget 20)
/effort high     →  Effort set to high (turn budget 40)
```

Настройка сохраняется и применяется со следующего запуска агента; это то же
значение, что и в Настройки → Agent settings → Effort.

## Добавление команды

Команды находятся в `app/src/main/java/io/finett/droidclaw/chat/SlashCommand.java`.
Зарегистрируйте команду в статическом блоке — имя, подсказка и обработчик,
возвращающий ответ в markdown:

```java
register("mycommand", "что делает команда",
        (arg, settings) -> "ответ в **markdown**");
```

Список подсказок и автодополнение подхватывают новые команды автоматически.
