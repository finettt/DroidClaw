# Установка окружения Linux

DroidClaw может запускать реальные Linux-команды внутри закреплённого базового образа Ubuntu 24.04.5. Образ выбирается по ABI устройства: для `arm64-v8a` используется Ubuntu `arm64`, для `x86_64` — `amd64`. Команды запускаются через PRoot, который позволяет гостевой файловой системе находиться внутри папки данных приложения без root.

## Включение окружения

1. Откройте меню приложения и перейдите в **Настройки агента**.
2. Нажмите **Окружение Linux**.
3. Нажмите **Установить Ubuntu**.

DroidClaw загрузит закреплённый архив Ubuntu, проверит SHA-256, распакует его, запишет настройки DNS и источников APT и отметит образ как готовый. На экране отображаются текущее состояние и прогресс загрузки. Когда образ готов, на экране появляется сообщение о готовности.

Образ и загруженный архив хранятся в приватном каталоге приложения `files/distro/`. Они исключены из резервного копирования Android. Нажмите **Удалить образ**, чтобы удалить оба.

Включение окружения не меняет, как запускаются shell-команды. Оно только предоставляет образ. Backend оболочки тоже должен быть установлен на локальный устройство, чтобы `execute_shell` запускался через образ.

## Лимит диска

Параметр **Лимит диска (МБ)** по умолчанию равен 2048 МБ. Перед установкой DroidClaw проверяет, что на разделе данных приложения достаточно места для этого лимита, архива и запаса. Тот же лимит на стороне Android доступен для последующих команд distro.

Это рекомендуемый предел, а не квота файловой системы. PRoot не может запретить процессу внутри Ubuntu занять больше места. DroidClaw измеряет образ со стороны Android и может отклонять последующие операции distro при превычении лимита, но не обеспечивает жёсткую квоту.

Чтобы сохранить образ малым:

- Выполняйте `apt clean` после установки пакетов.
- Удаляйте ненужные пакеты командой `apt remove`.
- Повышайте лимит диска в настройках, когда проект требует больше места.

## Использование apt и pip

Образ — это стандартный базовый Ubuntu, поэтому APT и pip работают внутри него.

- Установка пакета: `apt update && apt install -y <name>`
- Менеджер пакетов Python: `pip install <name>` (установите pip через менеджер пакетов, если его нет)

Операции APT требуют доступа к сети на устройстве. PRoot не добавляет GPU или аппаратное ускорение, поэтому вычислительноёмкие команды выполняются на скорости трансляции CPU.

## Ограничения

- PRoot — это слой трансляции, а не полноценная виртуальная машина. Некоторые команды, нуждающиеся в функциях ядра, файлах устройств или привилегированном монтировании, могут не работать.
- Нет ускорения GPU. Графические или вычислительные нагрузки выполняются на CPU.
- Лимит диска является рекомендуемым. Процесс внутри образа может занять больше места, чем лимит, пока DroidClaw не измерит его и не отклонит следующую операцию.
- Агент запускается как фоновая служба с приоритетом. На Android 12 и выше Phantom Process Killer может остановить фоновую работу при освобождении памяти системы, поэтому долгоиграющая команда distro может быть завершена, если приложение надолго остаётся в фоне. Держите приложение на передном плане для длинных команд.
